# AniStream Pro (ZenithAnime)

React 19 + Vite + Tailwind v4 anime streaming demo (localStorage based, no backend).

## Run
```
npm install
npm run dev          # http://localhost:3000
npm run build        # normal production build -> dist/
npm run build:single # ek single index.html -> dist-single/
npm run lint         # TypeScript check
```

## Demo accounts
Login screen par demo user switch available hai; admin user ke liye Admin Dashboard menu mein aata hai.
Data browser ke localStorage mein save hota hai.

## Deploy (free)
`dist/` folder ko Vercel / Netlify / Cloudflare Pages par upload kar do.
